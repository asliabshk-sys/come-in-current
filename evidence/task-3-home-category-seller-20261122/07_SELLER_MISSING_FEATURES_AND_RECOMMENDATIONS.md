# Report 7 — Missing Features and Recommendations

## Essential discussion items

- Decide a limited launch category taxonomy and a migration plan before changing flat IDs or product mappings.
- Define the operating policy for directory-only Stationery/Medical entries versus online commerce.
- Define seller dashboard success metrics and whether a dedicated overview/low-stock screen is required.

## Important optional items

- Dedicated low-stock/inventory-history seller UI.
- Seller daily/weekly/monthly export/report UX beyond current earnings date filtering.
- Seller notification delivery verification and complaint-management workflow refinement.

## Future expansion

- Advertising/premium membership, shop-performance analytics, verified bank ownership, provider-backed settlements, and native seller UI/device validation.

## Existing features requiring evidence, not rebuild

- Shop/product/order/import/financial routes already exist; do not rebuild them.
- OCR/PDF/CHAND capabilities need configured adapters and real non-production verification, not source replacement.
- Full Home/customer/seller visual flow needs safe runtime/device evidence.

## Security/permission follow-up

Source contracts show ownership/role guards, staged imports and validation. Production security, actual provider settlement and deployed configuration remain external validation gaps, not Task 3 source-change authorization.
